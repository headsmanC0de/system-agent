# Biome

**Repo role:** JavaScript/TypeScript linting, formatting, import organization, and editor diagnostics. See [VERSIONS.md](../VERSIONS.md) for the lock-resolved version.

Root `biome.json` is the SSOT; workspace configs extend it. Run `npm run lint`, or the desktop `lint:fix`/`format` scripts. CSS is deliberately excluded. Keep the schema URL on the installed version and treat warnings intentionally rather than accumulating suppressions.

Primary docs: [Biome guide](https://biomejs.dev/guides/getting-started/), [configuration](https://biomejs.dev/reference/configuration/), [CLI](https://biomejs.dev/reference/cli/), [repository](https://github.com/biomejs/biome).
