# @tailwindcss/language-server

**Repo role:** Tailwind-aware completions and diagnostics for CSS/TSX in OpenCode-compatible editors. See [VERSIONS.md](../VERSIONS.md) for the lock-resolved version.

The executable is `tailwindcss-language-server --stdio`. Run the repository-installed binary; do not depend on a user's global PATH version. The server supplements, but does not replace, the Vite/Tailwind production build or visual tests.

Primary docs/source: [Tailwind CSS IntelliSense repository](https://github.com/tailwindlabs/tailwindcss-intellisense), [Tailwind editor setup](https://tailwindcss.com/docs/editor-setup).
