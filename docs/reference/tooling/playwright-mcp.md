# @playwright/mcp

**Repo role:** accessibility-first browser control for agentic exploratory QA. The exact local version is generated in [VERSIONS.md](../VERSIONS.md) and shared by repository MCP configurations.

This is distinct from `@playwright/test`. Launch the lock-installed binary rather than registry-latest `npx`; use an isolated browser profile and keep Chromium's sandbox enabled. MCP findings are exploratory evidence until encoded as deterministic Playwright tests. Scope the server to QA agents because a browser is a privileged external-content boundary.

Primary docs/source: [Playwright MCP repository](https://github.com/microsoft/playwright-mcp), [configuration options](https://github.com/microsoft/playwright-mcp#configuration), [releases](https://github.com/microsoft/playwright-mcp/releases).
