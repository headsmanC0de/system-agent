# clsx

**Repo role:** conditional class-string construction inside `@project/ui`. See [VERSIONS.md](../VERSIONS.md) for the lock-resolved version.

Use `clsx` for conditionals, then pass the result through the shared `cn` helper where Tailwind conflict resolution is required. Avoid duplicating class-composition helpers in application code.

Primary docs/source: [clsx repository](https://github.com/lukeed/clsx), [npm package](https://www.npmjs.com/package/clsx).
