# @tailwindcss/vite

**Repo role:** compiles Tailwind CSS through Vite. Resolved versions in [VERSIONS.md](../VERSIONS.md) must keep the plugin and framework aligned.

Registered in the renderer plugin list. Keep both Tailwind packages on the same release line and do not add the legacy PostCSS/config pipeline unless a measured requirement appears. CSS changes should pass build and visual regression checks.

Primary docs/source: [Tailwind Vite setup](https://tailwindcss.com/docs/installation/using-vite), [Tailwind repository](https://github.com/tailwindlabs/tailwindcss).
