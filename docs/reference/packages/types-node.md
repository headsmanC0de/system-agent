# @types/node

**Repo role:** compile-time Node APIs for Electron main/config/test code. The resolved version is in [VERSIONS.md](../VERSIONS.md).

This package supplies types only; it does not change the host or Electron runtime. The tooling doctor derives both majors and rejects Node types that do not match Electron's embedded Node runtime.

Primary docs/source: [Node.js API docs](https://nodejs.org/docs/latest-v24.x/api/), [DefinitelyTyped Node definitions](https://github.com/DefinitelyTyped/DefinitelyTyped/tree/master/types/node).
