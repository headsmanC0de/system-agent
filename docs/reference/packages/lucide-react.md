# lucide-react

**Repo role:** renderer icon components. See [VERSIONS.md](../VERSIONS.md) for the lock-resolved version.

Import individual named icons so the bundler can tree-shake. Icons are decorative unless they carry meaning; accessible controls still need a text label or `aria-label`. Keep icon sizing/color aligned with shared semantic UI tokens.

Primary docs/source: [Lucide React guide](https://lucide.dev/guide/packages/lucide-react), [icon catalog](https://lucide.dev/icons/), [repository](https://github.com/lucide-icons/lucide).
