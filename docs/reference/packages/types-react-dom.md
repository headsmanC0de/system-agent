# @types/react-dom

**Repo role:** React DOM TypeScript declarations. See [VERSIONS.md](../VERSIONS.md) for the lock-resolved version.

Keep the major aligned with `react-dom` and React. It is compile-time only; renderer behavior comes from the locked runtime packages and Electron's Chromium.

Primary docs/source: [React DOM reference](https://react.dev/reference/react-dom), [DefinitelyTyped React DOM definitions](https://github.com/DefinitelyTyped/DefinitelyTyped/tree/master/types/react-dom).
