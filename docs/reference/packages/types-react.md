# @types/react

**Repo role:** React TypeScript declarations. See [VERSIONS.md](../VERSIONS.md) for the lock-resolved version.

Keep the major aligned with the installed React line. Type-only regressions can reveal real component contract changes; do not paper them over with local ambient declarations. Validate with the root typecheck.

Primary docs/source: [React TypeScript guide](https://react.dev/learn/typescript), [DefinitelyTyped React definitions](https://github.com/DefinitelyTyped/DefinitelyTyped/tree/master/types/react).
