# @vitejs/plugin-react

**Repo role:** React JSX transform and Fast Refresh for the Vite renderer. See [VERSIONS.md](../VERSIONS.md) for the lock-resolved version.

Configured in `electron.vite.config.ts`. Keep it aligned with the installed Vite line and use the current Oxc-based path without implying a general Babel pipeline. Test development refresh and production build after configuration changes.

Primary docs/source: [plugin README](https://github.com/vitejs/vite-plugin-react/tree/main/packages/plugin-react), [releases](https://github.com/vitejs/vite-plugin-react/releases).
